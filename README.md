# Retag

Retag is a free photo metadata editor and remover for Android. It shows the details hidden inside a photo, such as where and when it was taken and on which phone, and lets you change them or take them out before you share. The work is done on the phone, so photos are never uploaded. It has no adverts, no accounts and no paid version.
